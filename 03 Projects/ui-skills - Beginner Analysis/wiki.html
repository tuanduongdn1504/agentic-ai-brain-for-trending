What it is

AI agents ship UIs faster than ever — and they trend toward averaged-out slop: same fonts, gradient hero, rounded cards, layout drift, missing a11y. ui-skills gives an agent a discovery + fetch layer over design-engineering skills.

  • A CLI — start prints the ui-skills-root router-skill that teaches the agent to pick the right sub-skill; categories, list --category motion, get baseline-ui fetch skill markdown on demand.
  • A registry — src/data/registry.ts, 262 skills / 31 topics, most pointing at skills hosted in other repos (a curated aggregator, not a monolithic collection).
  • ~6 first-party skills — baseline-ui, improve-ui, fixing-accessibility, fixing-metadata, fixing-motion-performance, ui-skills-root.
  • An Astro site (ui-skills.com) on Cloudflare — the human-browsable index.

Aggregates skills from MengTo/Skills, vercel-labs (v51), antfu, anthropics/skills, pbakaus (impeccable v75), mattpocock (v57), shadcn, wshobson, and more.
