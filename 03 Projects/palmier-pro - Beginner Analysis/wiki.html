Not what the name suggested

This vault's history is full of code-context and code-graph MCP servers — graphify, GitNexus, codegraph, codebase-memory-mcp. Given the MCP angle, that was the first guess for palmier-pro. It's wrong.

Palmier Pro is a native macOS video editor. Its “for AI” tagline means two distinct things at once: generative video/image/audio models (Seedance 2, Kling 3, Nano Banana Pro, Veo, Suno) are wired directly into the timeline, and the app ships its own MCP server so an external coding agent — Claude Code, Claude Desktop, Codex, or Cursor — can open a real editing session and drive the timeline directly: read state, add or trim clips, generate media, grade color, export.

A different, older product from the same two-person team is also called “Palmier” — a GitHub code-review tool, YC S24 2024. It's a separate repo and not the subject requested here.

Company, verified by hand

Palmier, Inc. is San Francisco-based, incorporated 2024, a Y Combinator S24 company with two disclosed founders: Marcos Rico Peng (CEO, UC Berkeley EECS, ex-LinkedIn infrastructure) and Harrison Tin (CTO, UC Berkeley EECS, ex-Microsoft). ~$500K raised from YC, Immeasurable, Interlace Ventures, Scale Asia Ventures and two named angels. No Anthropic affiliation — Claude, Codex and Cursor get equal billing as MCP clients.

Open-core, cleanly disclosed

GPLv3 covers the editor, the MCP server, and the in-app agent chat. The one closed-source piece is the generative-AI processing backend, gated behind a subscription.

Three subsystems, one dispatcher

~325 Swift files, SwiftUI + AppKit, Metal shaders for compositing. Read at the source (clone verified, not just the README):

Editor

Timeline & preview — ripple/overwrite engines, snapping, keyframes, color grading, frame-accurate AVFoundation compositing.

→
Agent / MCP

HTTP MCP server on 127.0.0.1:19789. A single ToolExecutor dispatches 51 tools — get_timeline, add_clips, generate_video, apply_color, export_project…

→
Generation

Multi-provider video/image/audio abstraction, per-model cost estimate, async submit→poll→auto-import.

The MCP tool layer is the single best-tested part of the codebase — 1,885 lines in ToolExecutorTests.swift alone, out of 13.9K test lines total. Distribution is a signed & notarized DMG with Sparkle auto-update; no curl|bash, no postinstall scripts. Honest gaps: no published benchmarks, an undisclosed Sentry telemetry-consent flow (opt-out, default-on), no checksum published for the DMG itself.
