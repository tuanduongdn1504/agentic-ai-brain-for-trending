01 What it actually is

Point OpenAI's Vision + gpt-image models at photos of you in clothes. It detects each garment, reconstructs a clean transparent-PNG cutout of it, optionally renders a modeled preview on a reference model of you, and stores it all in a local JSON database + images you edit by drag / drop / paste / approve / regenerate. A web UI (bring your own key) and two Codex agent skills — $import-clothes and $generate-outfits — run the same pipeline interactively or from the CLI. It ships no MCP server.

Corpus-first for the personal-fashion / AI-wardrobe domain, and the first OpenAI-employee-authored subject — but NOT world-first: Acloset, Google Photos Wardrobe, Pocket Wardrobe, Scenario, SELION and the wardrobe-app GitHub topic populate the genre.

02 The pipeline — the reason it's worth reading

From the published extract-clothing-cutouts skill: an eight-stage, evidence-based flow governed by one rule — “prefer omission over invention.” Reconstruct only from what's visible; never guess hidden construction, branding, or unreadable text.

1 · discover

Normalize

Photos → high-quality JPEG working copies, EXIF orientation applied.

2 · detect

Inventory

Vision catalogs every garment into structured JSON — description, confidence, source ref.

3 · crop

Gen refs

Padded crops keep context while the garment stays dominant.

4 · prompt

Evidence prompts

Instruct gpt-image to reconstruct the item, remove wearer / body / background.

5 · key

Chroma extract

Generate on a #00ff00 key → remove → transparent RGBA PNG.

6 · verify

QA gate

Inspect vs the source crop: identity, proportions, color, artifacts. Reject / regenerate.

7 · merge

Dedup

Conservatively merge only source-proven duplicates.

8 · store

Catalog

Accepted PNGs + JSON entries; intermediates deleted.

04 The transferable idea → hireui CV-parsing

Strip the fashion domain and what's left is a reusable pattern: a vision model extracts N structured entities from an image into a confidence-scored JSON manifest, with an anti-fabrication discipline and a verify-against-source gate. That is exactly what hireui needs to parse CVs without hallucinating experience.
