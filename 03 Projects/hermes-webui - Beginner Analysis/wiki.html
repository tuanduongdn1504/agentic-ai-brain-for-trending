What it is

A lightweight, dark-themed, self-hosted web + mobile front-end for Hermes Agent — the autonomous personal agent by Nous Research that "lives on your server… remembers what it learns and gets more capable the longer it runs." hermes-webui gives that terminal agent full-CLI-parity browser access: a three-panel layout (sessions · chat · workspace file browser), streaming chat, and controls in the composer footer. Its own site labels it "Community Web UI (unofficial)." It is not the agent — it reuses an existing Hermes install's models and config.

Author Nathan Esquenazi (nesquena), a disclosed individual (CodePath.org co-founder), not Anthropic. Hermes Agent is a recurring named harness across the corpus (cc-switch v73, ECC v78, open-design v83) but was never a wiki subject — this is the first repo in the Hermes ecosystem to be one, and it's the UI layer.

Architecture (documented; not source-cloned)

No build step

Python standard-library HTTP server + vanilla JS — no framework, no bundler, no toolchain.

Three-panel UI

Sessions/nav · chat · workspace file browser with Git; CSS-variable themes (dark/light/Catppuccin/Geist).

State

SQLite sessions at ~/.hermes/webui/; projects, tags, pin, archive, search.

Access model

localhost :8787 + SSH tunnel; optional password / passkeys (WebAuthn) / OIDC.

Provider-agnostic

OpenAI · Anthropic/Claude · Google · DeepSeek — inherited from Hermes. Claude one of several.

More

Voice input, profile switching, cron/Tasks panel, slash commands, mobile-responsive; Docker/Nix/systemd/launchd.
