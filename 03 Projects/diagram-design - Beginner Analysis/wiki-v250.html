The Decidability Line

The finding

Six rules called non-negotiable. One of them has a gate.

The last four ships in this corpus turned on one axis: a guarantee written as prose addressed to a language model is not a guarantee; a guarantee compiled into a gate that can fail is. One subject engineered beautiful loud failures for its users and shipped behind a suite that could not fail. One wrote a mutation tester and wired it to nothing. This is the first subject that states the rule for which half is which.

SKILL.md:261 says of its six connector rules: “These six rules are non-negotiable.” Five are unguarded prose. The sixth is enforced by verify-geometry.py — and the checker’s own docstring explains the selection criterion.

You can only compile the part of your aesthetic that becomes a lie when violated. The rest stays prose. The borrowable rule — and the reason the treemap checker exists too: area is the encoding, so a mismatch is not a preference

The same criterion drives the second gate. verify-treemap.py computes each cell’s share of drawn area against the share its own label claims, and fails when they diverge — because a treemap whose areas disagree with its numbers is a chart that lies. Its error message names cause and remedy in one line: “Area is the only encoding; resize the cell.”

The reasoning is more sophisticated than it needed to be. Error is measured as a relative figure, not percentage points, and the docstring explains why: “a 0.13pp slip is noise on a 59% cell and a quarter of a 0.5% cell, so an absolute threshold passes exactly the cell most likely to be wrong.” Their own 4px grid is what creates the residue, and it lands hardest on the smallest cells — so they chose the metric that survives their own rule.

The honest counterweight

AREA_TOLERANCE = 8.0, deliberately loose so grid snapping never trips it. It catches gross area lies, not subtle ones. And calling all six connector rules “non-negotiable” oversells five of them: an agent that emits a diagonal fails nothing, in CI or on your machine.

The drift

Every counter they aimed is right. Every surface they didn’t aim at is stale.

The true count is 28, established by enumeration. Two independent scripts count it. An ADR calls it “a stable, verifiable claim.” When treemap made it 28, the amendment procedure was followed correctly. And it is still 27 in three places.

A PR that edits them without amending this file has quietly made itself the authority. Amend here in the same PR, or the number in the test is just whatever the last contributor typed. docs/adr/0002, Amendments — the best sentence in the repository

That is a real observation about mechanised invariants: a hardcoded expected value in a test is not a specification. It is a record of one person’s intent at one moment, editable by the same pull request that violates it. The gate does not know the right answer — it knows the answer someone typed.

The two unwired scripts are a developer version-bump utility and the skill-internal self-check whose own test is wired. There is no continue-on-error and no || true anywhere; the 25 if: always() steps make every gate report in one push while each failure still fails the job. Three jobs, a 3-OS × 2-Python matrix, plus a Python 3.9 compatibility job — they test the oldest interpreter a stranger might have.

Vault rule D34 — a committed CI rule is not an enforced one — has failed at every subject that met it recently. This is the first clean pass. The finding here is not that they failed to wire their gates. It is that the gates are excellent, so the drift moved to where the gates are not.

The transferable one

A skill’s description is infrastructure, not documentation.

ADR 0004 records a regression worth more than the rest of the repository to anyone who writes agent skills. A byte cap was set at 35,000 to keep SKILL.md lean. To fit, they slimmed the frontmatter description — deleting the type names.

The description is the only text an agent sees before deciding to load the skill: removing “flowchart”, “Gantt”, “org chart” from it removes the lexical hooks that make “make me a flowchart” invoke the skill at all. docs/adr/0004 — a byte budget that silently broke invocation

The fix ranks description completeness above their own byte budget — “routing surface is never traded for body prose” — and mechanises both: every type in the selection table must appear in the description, and MAX_SKILL_BYTES = 40_000 is enforced in CI. SKILL.md currently sits at 37,778 bytes — 94.4% of cap, with 2,222 bytes of headroom.

This is the exact inverse of an earlier ship which found that blanking an agent’s tool injections improved its reasoning. Together they bound the problem from both ends: strip the catalogue and the model reasons better; strip the description and the model never arrives.

One more gate worth stealing

The same script asserts that the semantic-pattern router precedes the visual-type guide — a CI check on the order of prose in an agent-facing file, mechanising the intent that behaviour is chosen before layout.

The calibration

The aesthetic checks guard their gallery, not your diagram.

What installs onto your machine is three files and 2,603 lines. The only output checker among them is self_check.py — 389 lines covering the accessible-SVG contract, single-file safety, and the motion contract. The skin linter, the geometry checker and the treemap area checker all stay in the repository.

So the promise of accessibility and safety is code, shipped. The promise of editorial quality is a 37-item prose checklist addressed to the model. That is defensible — accessibility structure is decidable and taste is not — and to their credit the checklist says so item by item, distinguishing “in this repository” from “from an installed skill, manually check.” But state it plainly rather than repeating the marketing.

The best-designed part of that checklist is the part no machine could ever run — the remove test: can I remove any node, merge any two, remove any arrow, remove any label? — preceded by the gate that matters most: “Would a table or paragraph do the same job? If yes — don’t draw.” A diagram tool whose checklist opens by asking whether to draw at all.

Ledger

What this run got wrong.

Seven errors, three mine and all self-caught, four from a 19-agent fleet that completed cleanly at ~2.27M tokens.

  • Mine. “The 27 exists only in GitHub settings” — wrong; a broader grep found two shipped command files. My first pattern missed the phrasing “one of the 27.”
  • Mine. Called two verifiers dead gates for missing types; both are documented variants inside their parent type files, and one is the feature at HEAD. Evidence for the project, not against.
  • Mine. Estimated the checklist at 41 items. It is 37.
  • Fleet. Declared the byte cap “aspirational, not enforced.” It is enforced in CI across six runners. The agent searched only SKILL.md, did not find it there, and read absence of evidence as evidence.
  • Fleet. Two more checklist counts — 28 and 35. Both wrong. Settled with grep -c, not authority.
  • Fleet. A mapper, a contradiction pass and the critic all escalated one example set as an undocumented type. It is documented, in its parent type file, three lines of prose away.

The last item and my second error are the same trap, and it caught me and three agents independently: a filename that omits its parent makes a documented child look orphaned to any inventory check, human or machine. Both times the fix was to stop diffing filenames and read the parent file.

And the pattern from the previous ship held for a third time: the contradiction stages did real work, but the error that would have embarrassed this document — a live CI gate declared imaginary — was caught by running the check myself.

Verdict

Install it, fenced — then take the three rules whether you install or not.

No mint. A clean instance of the confirmed anti-slop-curation pattern at its machinery-with-enforcement pole, joining a seven-member design-skill cluster. Anthropic ships first-party diagramming guidance for agents and renders Mermaid natively in artifacts; “declarative source to opinionated diagram” is a mature category. The genuinely novel axis — machine-verified output geometry — is a technique rather than a capability class, and it does not ship to the user. Recorded as the reviewable alternative, not executed: a mint is an audit act.

Security is low and structurally clean — no server, so the broken-authentication triad cannot occur; no lifecycle scripts; no telemetry; a font allowlist pinned to an exact host and path with lookalikes rejected; a real propose-diff-then-approve gate. One named gap: brand onboarding fetches a live website into the agent’s context and nothing anywhere treats that page as untrusted text. Worst realistic outcome is an ugly diagram, but the sentence is missing.

Ninety seconds, zero risk: open the gallery and decide whether you like the output. Nothing else matters if you don’t.

Two hours, zero install, the rung that pays: make the vault’s inventory checks bidirectional. This project proved the principle in a controlled experiment inside one file — and the vault has a state file whose filename has lagged its contents for eleven consecutive ships, re-described in prose every time and never once detected by a script.
