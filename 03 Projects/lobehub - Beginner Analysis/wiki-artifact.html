What it actually is

The repo that was lobehub/lobe-chat until 2026 — LobeChat, a self-hostable, design-forward, bring-your-own-key ChatGPT/Claude alternative that puts OpenAI, Anthropic Claude, Google Gemini, DeepSeek and local models (Ollama) behind one polished UI, with plugins, a knowledge base (RAG) and voice. The 2026 LobeHub rebrand widened it into an ecosystem: LobeChat + a Chief Agent Operator + agent teams + a skills/MCP marketplace + a desktop app.

Read the framing skeptically

"Chief Agent Operator," "7×24 operations," "273,000 skills," "hire your AI team" is aspirational product-marketing layered on a genuinely excellent, battle-tested multi-model chat + agent-builder core. The chat core is 3+ years mature; the CAO / agent-teams / cloud-parallel pieces are newer and marketing-forward. (Metric split, §37.4: README says "10,000+ skills"; the site says "273,000" — both page-stated.)

The four pillars (decoded)

  • Operator — hires/schedules/reports on your agents; an IM Gateway puts agents inside Slack, Discord, Telegram, WeChat, Feishu, Lark, LINE, QQ & iMessage.
  • Create (Agent Builder) — describe once → auto-configured agent; any model + modality; tools + MCP-compatible plugins (host side).
  • Collaborate (Agent Groups) — Pages, Schedule, Project, Workspace — "agents as real teammates."
  • Evolve (Personal Memory) — Continual Learning + White-Box Memory (structured, editable, transparent — inspect & fix what the agent remembers).
