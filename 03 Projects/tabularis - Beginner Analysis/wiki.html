01 What it is

A cross-platform desktop database client (DBeaver / TablePlus / DataGrip class) supporting PostgreSQL, MySQL/MariaDB and SQLite built-in, plus 13+ more (DuckDB, ClickHouse, Redis, Firestore, BigQuery, MongoDB, Oracle, SQL Server…) via a language-agnostic JSON-RPC 2.0 plugin system. On top of the GUI: SQL notebooks (SQL + Markdown + charts), visual EXPLAIN plan graphs, ER diagrams, a drag-and-drop query builder, SSH tunnelling, keychain secrets, a nine-language UI.

The distinctive claim is "the MCP-native database client." You connect databases once in the GUI; your agent reaches them through the same connection profiles — "without duplicating config, without pasting secrets, without building your own bridge." Explicitly the opposite of bolt-on AI: it exposes the database to the agent rather than putting the agent inside the app.

The MCP server — 4 tools, gated by design

list_connections · list_tables · describe_table · run_query. One-click config for Claude Desktop, Cursor, Windsurf (+ Claude Code, Devin). Credentials stay local; per-connection read-only mode + approval gates with pre-flight EXPLAIN that "fail closed on anything ambiguous — including stacked multi-statement payloads." Text-to-SQL runs over OpenAI / Anthropic / MiniMax / OpenRouter / local Ollama / any OpenAI-compatible endpoint.
