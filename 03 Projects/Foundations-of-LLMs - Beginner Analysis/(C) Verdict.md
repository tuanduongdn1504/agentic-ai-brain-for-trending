## The finding

**Every defect in this repository is a promise about the future — and a promise about the future is the only claim class that cannot be wrong when it is written.**

Eleven assertions of ongoing maintenance: 「持续进行月度更新」 · 「当前正处于不断更新中」 · 「所有提出issue的人，我们都列举在此」 · 「后续…还将继续探索…大模型智能体」 · 「It will be coming soon!」 · 「本书持续更新」 **×9 inside the PDF** · `version-1.0.0`.

Not one was false on the day it was typed. All are false now. **No gate can fire at write time on a statement that is honest at write time** — which is why none of these was ever caught, while a wrong count or a dangling link would have been caught immediately.

The measurements:

- **Book content frozen 2024-12-04 — 20.7 months** — under a live monthly-update promise unchanged across **17 README revisions**.
- **62 issues raised. Zero names in the gratitude list, in every revision, ever. Four blank lines where they would go.**
- **I verified the newest errata report (#68, filed 2026-07-21) directly against the shipped PDF** — §3.3's summary reads 「按部就班、按部就班以及集思广益」, listing mode one twice and omitting 三思后行. The reader is right; the error is still there; they are not thanked; and **they cannot fix it** — no source, and NoDerivatives forbids sharing a corrected copy.
- **The freshness claim is welded into the artifact**: nine copies inside a 290-page PDF nobody outside the lab can recompile — while the book states its own age **zero times**.
- **The only maintenance the project received in its final year went to the part that advertises something else.**
- **The most goal-relevant content is in the directory the README never mentions** (60 files, 80% of tracked files, zero index references) — including a correct Claude Computer Use briefing, while the documented book mentions Claude once, as a figure label.

**The arc:** v267 the discipline stops where the artifact stops being code · v268 a gate exists where a reader can refuse · v269 no gate can see an entry that was never added · **v270 no gate can fire on a claim that was true when it was written.**

**The only defence is a date.** v255 already said *date your work*. This is what it costs not to.
