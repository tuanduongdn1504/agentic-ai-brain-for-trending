"Companies use AI to filter candidates. I just gave candidates AI to choose companies." — README. That inversion is why it matters: hireui scores candidates for employers; career-ops scores employers, and beats their ATS filters, for candidates.

What it actually is

The README markets "A-F scoring, 10 weighted dimensions." The code is more honest, and this wiki documents the code: the evaluation "brain" is Markdown prompt files (modes/_shared.md, modes/oferta.md) executed by whichever AI coding CLI you point at the repo — the coding agent IS the runtime, no orchestrator. The mechanics are ~50 single-job, mostly zero-LLM Node scripts; the surfaces are an optional Go TUI and an alpha web UI. The accurate label: an agent-first, end-to-end, candidate-side job-search / career-operations pipeline — the OpenMontage v188 shape applied to job search.

The pipeline

1 · DISCOVERscan.mjs + ~53 provider modules — zero Claude tokens (pure HTTP), --verify does a Playwright liveness pass
2 · SCOREmodes/_shared.md + oferta.md + your cv.md — 1–5, reasoning not keyword-match
3 · GENERATEATS-safe PDF CV + cover letter (defensive, not injective)
4 · TRACKdata/applications.md is canonical; SQLite is a derived index; strict data contract
5 · UPDATEupdate-system.mjs refreshes system files, never touches your data

The scoring rubric (code-authoritative)

A 1–5 global score, by default the average of the block scores (oferta.md:404), user-overridable. Five weighted dimensions; seven report blocks A–G; Block G checks posting legitimacy but does not affect the score.

ScoreMeaning (code, not the README's "<4.0")
4.5+Strong match — apply immediately
4.0–4.4Good match — worth applying
3.5–3.9Decent — only with a specific reason
< 3.5Recommend against applying

Dimensions: CV-match · North-Star alignment · Comp · Cultural signals · Red flags. Archetypes (customizable): LLMOps · Agentic · Tech-PM · Solutions-Architect · Forward-Deployed · Transformation. A workflow agent's "25/20/15/15/15/10% + a 6th 'intuition' dimension" and "Block G caps the score at 3.5" were both Haiku confabulations — contradicted by the source, not cited.

The transferable gold

The genuinely excellent, directly-portable parts — an ethics-forward, anti-hallucination system:

  • Anti-fabrication: "NEVER claim the user authored X unless attributed — tool-of-trade conflation (user uses X → user built X) is the most common fabrication pattern and is forbidden."
  • Honest reformulation: "Keywords get reformulated, never fabricated … silence beats manufactured detail."
  • Exclusive Sources-of-Truth boundary — only your own documents; no auto-memory, no cross-session inference.
  • Subagent cost guardrail: "single-pass workers, never nest, never call recursive research — can burn tens of millions of tokens."
  • Files are canonical, databases are derived (RFC #918) — the vault's own LLM-Wiki philosophy, shipped as product design.
  • Never auto-submit — baked into code (prepare-application.mjs "never POSTs"), not just the disclaimer.
