span · what it is

Five verbs, one desktop window

LLM Space operates on the agent you are building — not on a coding agent doing dev work (that's a different corpus family). You author the harness and it captures the whole run so you can replay and score it.

VerbWhat it does
BuildWrite & version prompts, system messages, tools, model settings
TraceObserve every model call & tool run inside the agent loop, in real-time
DebugReplay runs from history & step through execution to find the failure
EvaluateMeasure agent performance across multiple runs
ManageOrganize threads as files on the local machine (local-first)

stack  Electrobun native shell · React + Tailwind + shadcn · Pi Agent Core agent loop · Bun monorepo (packages/core + apps/desktop). VolcEngine/BytePlus is the recommended default provider; no MCP server; telemetry opt-out-default-on.

span · pilot

How to actually use this

On-goal and directly pilotable — its author → trace → replay → eval loop is exactly what the ratified candidate-LLM legibility ADR demands. The payoff is the discipline, not adopting a ByteDance product.

  • A1 → B5 → D16 ⭐ — read the five-verb loop → lift "trace every call, replay, eval across runs" into hireui's LLM-feature spec + the candidate-LLM ADR (eval/bias-gate outside the prompt) → use it as the dev-environment when you build hireui's first LLM feature (Match-Explain), traced & eval'd before it touches a candidate, on an agent-* branch.
  • C11 — install-snapshot → bun install in a scratch dir, drive a toy Pi agent through the loop. Telemetry off, BYO Claude key.
  • F22 — file the §C mint + the #57 + the DeerFlow same-team cross-ref for the ~v231 audit.
Fence. Not source-cloned → treat setup as untrusted (read mise run setup first). Telemetry is opt-out-default-on → turn it off. BytePlus/VolcEngine default = ByteDance egress → BYO keys, never point it at candidate PII with the default provider. Pin v4.2.0.
