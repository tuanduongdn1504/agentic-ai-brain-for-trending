What it is: a thirteen-package monorepo of community plugins and eleven skins for the official web GUI of DeepSeek Harness — the agent runtime this corpus shipped as v235. Its own motto: 一切皆开发，一切皆插件 — everything is development, everything is a plugin. One row installs the lot.

It adds a kanban task board with host-side cron, a git graph, a QR-paired mobile remote, an SSH operations console that also hands the model remote-execution tools, an image-understanding tool, an animated whale, a skin centre, a community-plugin index, and a two-phase agent preset. It is roughly six days old.

Finding 03 · mechanismThe gate is a regex on the model's thoughts

Phase one exposes only the host's builtin Minimal pair — persistent bash and str_replace_editor — clears runtime context, and drops workspace directives, snapshots and the skill directory.

Promotion fires on the first persisted tool call if the reasoning block passes the anchor gate. And the anchor gate, source-verified, is this: a block counts as "minimal-like" iff it matches /\bwe\b/gi and has zero matches of /\blet me\b/gi. verified

An architecture of phase machines and durable-event promotion rests on a two-token string test over model prose.

Phase two is not a larger catalog — it collapses to a single run_code tool reaching the full registry via generated SDK calls. Both phases minimise the visible tool surface; the second by making tools code rather than schema. And PTC mode is the host's own preset name: DSH rc.7's notes read "Rename the English Code mode preset to PTC mode." Both phases are compositions of first-party presets.

Finding 04 · governanceA required field for "which agent wrote this?"

The pull-request template carries a section headed AI 编码披露 — AI Coding Disclosure — marked required, with three mutually exclusive checkboxes (fully AI-coded / partially AI-assisted / no AI), then two fields: 使用的 AI 模型 (examples: DeepSeek, GPT-5, Claude Sonnet 4) and 使用的编码 Agent 工具 (examples: DeepSeek Harness, Codex, Claude Code, Cursor). verified

It is enforced: scripts/pr-review.mjs audits external PRs with REJECT/FAIL/WARN/PASS verdicts, size limits, worktree build verification — and missing-template-field checks. The norm reached reporters too; one issue closes with 大部分为 AI 的测试复现与代码推测，仅供维护者参考.

This is the corpus's first subject that treats AI authorship as structured, required provenance metadata in its contribution process.

Two-sided, and worth noticing

The same automation auto-closed issue #532 — a substantive bug report, with reproduction steps, about the v237 sidebar failing to load when also installed standalone — for template non-compliance. Borrow the field. Do not borrow the severity.

And a quieter tension: in a repo whose PRs are declared fully AI-coded, a CI gate that bans emoji across four Unicode ranges is not only style enforcement — it suppresses one of the most reliable AI-authorship tells. The project requires the disclosure and erases the signature.

Finding 05 · securitySound in one half, hazardous in the other

Source-verified sound

  • Mobile pairing done properly — one-time 16-byte token, 10-minute expiry, consumed on first accept, revocable sessions; binding inherited from the host (loopback by default).
  • No broken-auth triad. Unlike v231 and v232, it does not ship 0.0.0.0 + wildcard CORS + fail-open auth. First in this run to get it right.
  • Port forwarding loopback-only. No telemetry.
  • CI is permissions: contents: read — no publish job, no secrets.
  • The pi v228 hardening playbook, independently adopted: exact-pinned deps, a allowBuilds lifecycle allowlist, minimum release age.

Source-verified hazardous

  • Six SSH tools registered into the agent — ssh_list, ssh_exec, ssh_upload, ssh_download, ssh_tunnel, ssh_cluster. ssh_exec takes an arbitrary command.
  • No allowlist. No approval gate. No audit log. No output redaction. No read-only mode.
  • SSH passwords and key passphrases written plaintext to ~/.dsh/dsh-ssh.json.
  • Reconnect "may replay non-idempotent commands."
  • The one-line install transitively pulls cloudflared, whose postinstall downloads a tunnel binary.
The corpus already knows the answer

tabularis v212 — one ship earlier — solved this exact secret class with the OS keychain, and gated its agent surface with read-only mode, approval gates, and a pre-flight EXPLAIN that fails closed. Same problem, done properly, already in the record.

And to be fair to this project: the defect is disclosed verbatim in both READMEs. Careless design, honest documentation.

The scheduler, by contrast, is careful — and corrects a risk I first overstated. Every run opens a separate session with a pinned workspace, preset and permission applied before the prompt; it is fail-closed (a rejected permission aborts before the prompt reaches the model); missed cron occurrences are skipped, never queued; runs never overlap; and prompts are queued into the normal interaction flow rather than auto-approved. verified

A four-ship theme

v233 — evaluation fails closed. v234 — ingestion fails soft. v238 — fail-soft at runtime, fail-fast at config. v239 — scheduling fails closed. Four unrelated projects converging on failure mode as the thing worth being explicit about.

RulingNo mint, and why the close call lost

Counts unchanged at 46 / 11; 49 live standalones unchanged. Three watch axes strengthened, none promoted — a promotion is an audit act.

Declined: the plugin-and-skin suite

Emphatically not world-first. "Plugin + theme pack for an extensible host application" is canonical and decades old — VS Code extension packs and its theme marketplace, Obsidian's ~6,730 plugins and ~698 themes, Home Assistant HACS, Grafana, JupyterLab, Eclipse before them all. Packaging, not capability. And the precedent chain now runs six deep.

Declined, but closer: the SSH capability layer

Genuinely corpus-first by grep — SFTP, port forward, cluster execution, ttyd, Guacamole, Cockpit, Portainer all return zero, and the corpus's twelve SSH hits are all SSH-as-transport-to-reach-an-agent, never SSH as a capability the agent wields. It loses on four grounds: agent SSH tools and browser SSH consoles are both well-precedented; it is one package inside a thirteen-package suite, so minting draws the circle around a component; it is the weakest-engineered part of the subject, and minting vocabulary off a project's worst code encodes a liability as a class; and anti-inflation. Recorded as a deferred watch axis — and flagged with emphasis, because it is the corpus's first instance of an agent handed production-fleet reach.

The near-miss worth naming

The task board's surface similarity made "third instance of the Multi-Vendor Orchestration Platform" tempting — until the row was read verbatim. It requires heterogeneous third-party agents as the orchestration units. This board is single-host, DSH-only. Not an instance.
