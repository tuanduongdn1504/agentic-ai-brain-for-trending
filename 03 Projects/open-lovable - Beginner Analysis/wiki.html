Give it a website URL or a chat prompt. Firecrawl scrapes the target into clean, LLM-ready content; an LLM of your choosing — Claude, GPT, Gemini, or Groq — generates a modern React + TypeScript + Tailwind + shadcn/ui app from it; the generated code runs live in a secure Vercel or E2B sandbox; you chat to iterate and download the code you own. It is the corpus's first prompt-to-app / AI-app-builder subject — the "clone any website" flavor of the Lovable / v0 / Bolt.new category — and, in Firecrawl's own words, "an example app made by the Firecrawl team."

01How it works

Scrape

Firecrawl renders the target site (handles JS + anti-bot) → clean HTML / structured LLM-ready markdown.

Generate

The chosen LLM writes a React 18+ / TypeScript / Tailwind / shadcn/ui app from that content.

Edit

Morph "Fast Apply" (optional) applies incremental chat edits fast — not a full regeneration.

Sandbox

The code runs + previews live in an isolated Vercel Sandbox (default) or E2B — untrusted generated code never touches your machine.

Iterate / own

Chat to refine; download the zipped React project and run it locally. You own the code.

The builder is a Next.js + React + Tailwind app at localhost:3000; requires a Firecrawl API key + ≥1 LLM provider key. MIT — no productization blocker, unlike Firecrawl's own AGPL-3.0 core.
