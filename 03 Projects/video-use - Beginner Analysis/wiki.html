01 What it is

A free, MIT Claude-Code (Codex / Hermes / OpenClaw) agent skill that edits existing raw footage by conversation.

Drop raw takes in a folder → run claude there → say “edit these into a launch video” → get edit/final.mp4. It cuts filler and dead space, color-grades, burns captions, generates overlay animations, and self-evaluates the render before showing you anything. By Browser Use, Inc. (YC W25, makers of the browser-use agent — corpus subject v41). Source-verified at commit 92c2b34.

License

MIT © Browser Use

Python 76% / HTML 23%. No releases, git-clone-only. Zero tests, no CI. ~15.9k★ (page-stated).

Not

Edits footage you shot — contrast OpenMontage v188, which produces a video from a brief. Not a GUI, not an MCP server.

02 The idea: read the video, don't watch it

The one genuinely novel thing here — and the reason it's the same org that built browser-use.

Two layers give the LLM word-boundary precision from text. Layer 1 (always loaded): one ElevenLabs Scribe call per source → word-level timestamps + speaker diarization + audio-event tags, packed into a single ~12KB takes_packed.md. Layer 2 (on demand): a filmstrip+waveform+word-labels PNG rendered only at decision points. Same thesis as browser-use giving an LLM a structured DOM instead of a screenshot — transplanted to a new modality.

Transcribe→ Pack ~12KB→ LLM reasons→ EDL→ Render (ffmpeg)→ Self-eval ⟲ max 3

The self-eval loop runs the visual composite on the rendered output at every cut boundary — catching visual jumps, audio pops, and hidden captions — and fixes + re-renders before you see a preview. A maker/checker discipline baked into a skill.
