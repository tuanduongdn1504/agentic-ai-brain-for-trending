03What it is

A terminal-first autonomous coding agent — three run modes: interactive full-screen TUI, headless (CI), or editor-embedded via the Agent Client Protocol (ACP). The headline feature: up to 8 concurrent subagents, each in its own Git worktree on a separate branch — one rewrites auth, another updates tests, a third refactors a migration — with an orchestrator reconciling their outputs. It hosts MCP servers and supports skills, agents, hooks, plugins, a marketplace, sandboxing, Plan Mode — the exact Anthropic-pioneered agent-primitive stack, now adopted cross-vendor.

04Two facts to report faithfully

Open license, one-way mirror. Genuinely Apache-2.0 ("the entire Grok Build codebase") — but a source-available mirror synced from the SpaceXAI monorepo with no external contributions accepted. Read/fork/borrow — don't try to PR.

The privacy incident. Open-sourced after a backlash: earlier versions uploaded working directories to Google Cloud. That upload path is now disabled and retention is off by default — the load-bearing fence point before pointing it at any real repo.
