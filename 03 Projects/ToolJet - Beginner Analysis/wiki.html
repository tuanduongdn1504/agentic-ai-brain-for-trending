01 — the thesis

Claude Code does not read AGENTS.md. ToolJet's answer is a symlink, not a second file.

The usual workaround for a harness that only reads its own filename is to keep two context files and try to remember to update both. ToolJet's answer is structural: one canonical file, and the other name is a view of it. A symlink cannot disagree with its target. This is the cheapest available answer to a problem the vault named one ship ago as D22 — agent-facing prose goes stale first: it removes the failure mode instead of policing it.

Canonical file: AGENTS.md; CLAUDE.md is a symlink to it.

AGENTS.md, line 3 — the convention documents itself
and the deployment is 3 of 13 defect

Thirteen directories carry an AGENTS.md. Only three — root, frontend/, server/ — get a CLAUDE.md beside them. The ten per-module context files, 59 KB of ToolJet's most specific guidance, are invisible to the harness their own commit trailers prove they use. The design is right; the bridge was built at a quarter of the crossings.

04 — the cause

The same problem, solved twice, seventeen months apart

ToolJet's enterprise code lives in two git submodules — frontend/ee and server/ee — and both are private. Verified at the git protocol level, not from a 404 page: git ls-remote on each demands credentials. So git clone --recurse-submodules cannot succeed for anyone outside the company, and every git operation inside it spans three repositories.

06 — the counter-example

They have the doctrine. They do not have the check.

Update its AGENTS.md in the same PR. … Stale context is worse than no context.

AGENTS.md — the living-docs rule

The policy is right, the update is required in the same PR, and there is a template to create a missing file from. Nothing verifies it — no linter, no CI job, no script in any workflow. And the consequence is already sitting in the tree.

plans/widget-css-class.md · committed 2026-06-24 rotted

One genuinely excellent implementation plan — with inline "(Grill correction — …)" and "(PM correction, 2026-06-18)" annotations and a phase tagged Type: AFK. Its header cites three companion documents. All three are missing from the repository. The body says "See ADR 0001." There is no ADR 0001 — there are zero ADR files anywhere. And no AGENTS.md mentions plans/ at all, so a linter comparing the context index to the code would never have flagged it. Eight weeks, unnoticed.

and this is what makes it an argument, not a complaint

The squashed body of the agent-layer commit preserves fifteen bullet subjects. Three of them are the prose-versus-code check performed by hand: docs: revise glossary against current code and docs · docs: align lint guidance with CI lint jobs · docs: remove accidentally committed context-mode tooling block. They ran the check three times, carefully, and produced excellent documentation — and the one artifact outside that review's scope rotted anyway. Care does not scale. A script does.

Counts unchanged: 46 / 11. Streak GA:101, 24 consecutive.

Two new decision rules

  • D26 — in a squash-merge repository, a grep over commit bodies counts pre-squash commits, not commits. ToolJet squashes 35.6% of its history; 165 commits carry 905 trailer lines. It also hides commits entirely — the agent layer's original is not an ancestor of main.
  • D27 — declare the ref population of every git count, and re-check it before accepting a refutation. This ship's adversarial verifier returned REFUTED twice, on two unrelated claims, both times by silently switching to --all — and both claims were correct as stated. Extends v241's D21: a verifier can check the right claim against the wrong population.

The payoff — under thirty minutes, all three

  1. Symlink the vault's own context files, so CLAUDE.md and AGENTS.md cannot diverge.
  2. Add a Flagged Ambiguities section to CLAUDE.md, opening with the -v183 label.
  3. Update the flaky-shell memory — it is the harness, not the machine, and now N=2.

Then the label check: assert that every _state/*.md filename's version range matches the entries it contains. Nine consecutive ships have now handed the vault a piece of that tool. ToolJet contributes the structural half — and the proof of what the policy alone buys you.
