§ 01 — What it isAgent-first Office documents

Point an AI agent at OfficeCLI and it authors real .docx/.xlsx/.pptx files. The distinctives that separate it from the field of thin Python MCP wrappers: a built-in HTML/PNG rendering engine (render-and-verify — the maker/checker loop applied to documents), a real Excel formula evaluator (350+ functions, auto-computed on write) + native pivot tables, a three-layer command surface, resident mode, and deterministic JSON I/O. It is delivered as an agent capability three ways at once.

Three-layer surface

  • L1 Read — view · get · query · validate
  • L2 DOM — set · add · move · remove · batch · path-addressed /slide[1]/shape[2]
  • L3 Raw XML — raw · raw-set (XPath fallback)

Delivered as an agent capability

  • MCP server — Claude Code · Cursor · VS Code · LM Studio
  • Auto-installed SKILL.md — Claude Code · Cursor · Windsurf · Copilot
  • SDKs — pip install officecli-sdk · npm i @officecli/sdk
