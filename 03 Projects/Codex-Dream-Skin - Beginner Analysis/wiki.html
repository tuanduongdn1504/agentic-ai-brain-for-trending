01What it actually does

Codex Desktop is an Electron/Chromium app, so its renderer exposes a Chrome-DevTools-Protocol port on loopback. Codex-Dream-Skin launches or attaches to that port after the app is running and pushes CSS plus a full-window background image straight into the live renderer. Because it injects into the running window rather than repackaging it, it never modifies .app / app.asar / WindowsApps / code signatures, never rewrites your API key or Base URL, and reverts in one click.

The sidebar, suggestion cards, project picker, and composer stay native, interactive controls — a wallpaper beneath the real UI, not a fake overlay. macOS ships a menu-bar switcher; Windows a system-tray one, with a persistent local theme store. Presets ("Gothic Void Crusade," "Arina Hashimoto," "romantic-rose") skew toward anime / gravure wallpapers — a taste note if it's ever near a work or shared screen.
