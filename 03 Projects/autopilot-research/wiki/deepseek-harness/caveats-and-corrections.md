# Caveats and corrections

> Everything this ship got wrong, everything the sources got wrong, and everything left unresolved. Per vault Rule 12: nothing skipped silently.

## Corrections made during this ship

**1. My own scorecard totals were wrong on first write.** I hand-counted 18 CONFIRMED / 14 CBI / 3 PLAUSIBLE / 4 MISLEADING / 1 FALSE / 5 UNRESOLVED / 2 UNVERIFIABLE. Tallying the table programmatically returned **24 / 10 / 4 / 4 / 1 / 3 / 1**. Both sum to 47, which is exactly why the error was invisible without the machine count.

> **Rule earned: a totals line derived by hand from a table you also wrote is not a check — it is a second guess. Tally the table.**

This is a live instance of the standing memory rule that *quoting a file you opened is reliable; enumerating and generalising is not.* Every quotation on these pages came from a transcript I read; the one number I generated by counting was wrong.

**2. Misapplied PIN, caught before it shipped.** The v242 PIN reads *"any star figure (159.0k★ is page-stated; the GitHub API is mocked, §37.4)."* My first framing treated "the GitHub API is mocked" as invalidating the videos' star counts. It does not: that finding (v239) is about **DSH's own web-UI tooling** mocking the API, so it invalidates figures *rendered inside DSH surfaces* — not figures read off github.com. The videos read github.com. Separate caveat, separate scope. Corrected in [[deepseek-harness/star-velocity-and-the-superlative]].

**3. NotebookLM deliberately skipped.** The routine's Path A pipes bundles through NotebookLM. For a claims scorecard that destroys the deliverable — you cannot grade a claim against a paraphrase of it. Captions were read in full instead (22,853 words), following the `engineer-of-the-future` precedent. Stated as a design decision, not a silent deviation.

## Source errors

**Cef — unqualified hot reload (the bundle's one outright FALSE).** *"when you modify a plugin, it gets updated without having to rebuild the application or relaunch it."* True for dynamic (creator-minted) plugins; false for installed presets, which Firecrawl shows are frozen at session start. Cef never tests a preset, so the error is untested generalization, not fabrication.

**Turing Post — confluence presented as a result.** The description is accurate and the limits are stated better than any other source. But the paper is a **preprint dated 2026-08-13, "under active revision,"** not peer-reviewed, and the video's framing ("the result is called confluence") reads as settled theory. Graded MISLEADING for framing, not content.

**Same-day star drift.** Cef's 135,000 and Turing Post's 147,000 are both 2026-08-17, against an official 141,532 that day. Better Stack's 150,000 on 08-19 is stale-low against 08-18 readings that already exceeded it. All within normal recording-to-publication lag. None is a fabrication.

**The scope error every source shares.** All six treat the curated catalogue (~1,400) as "the ecosystem." The `dsh-plugin` topic holds **8,874** repos. Nobody checks. See [[deepseek-harness/ecosystem-and-the-catalogue-gap]].

**The VN source's self-retraction, preserved.** He proposes that RC7 loosened the sandbox, then notices he had just switched his own permission tier and half-withdraws it. **Recorded as UNRESOLVED.** Resolving it toward the more interesting reading would have been the easy error here.

## Unresolved — carried forward

1. **"PTC"** — behaviour consistently described (batch tool calls into one script, cut context bloat), acronym never expanded by any source. The vault asserts no expansion.
2. **Localhost port** — Cef says 3080; VN says "3000-something."
3. **Cordis start year** — Better Stack "since 2022"; v242's copyright header "2021-present Shigma"; external reporting "four years" as of Aug 2026.
4. **RC6 → RC7 sandbox behaviour** — see above. The bundle's most pilot-worthy open question.
5. **TypeScript 97.1%** — page-stated language bar. v242's D23 (declare the language basis) applies to this repo's doc counts because of `.md`/`.zh.md` bilingual pairing; whether it distorts the *code* percentage is unchecked.
6. **Paper page count** — "~80 pages" is secondary-source only.
7. **Trajectory completeness** — "everything the model sees" is unverified by anyone; no source diffs the trajectory against the wire request. Given that plugins can modify the agent loop, a plugin could in principle inject context the trajectory doesn't show. Open question, not an alleged defect.
8. **Topic-count composition** — `open-design` (89.4k) and `reactive-resume` (41.2k) carry the `dsh-plugin` tag. An unknown share of the 8,874 is retrofitted tags on pre-existing projects rather than new plugin work, which would make the topic count a weak proxy for ecosystem development. Unmeasured.

## Method caveats on this ship

- **Bundle composition is hype-skewed and I flagged it before ingest, not after.** The rubric picked 5 hype-framed titles and **zero** skeptical/testing sources. The only sceptic found in the pool — CloudYeti's *"Is the Hype Real? LIVE Testing"* — sits at 891 views, below the drain's `MIN_VIEWS=1000`, so the rubric could not pick it. The bundle's counter-pole is therefore the source-verified corpus, not another video. Firecrawl's dissent and Chase AI's "probably not" partially compensate.
- **Two high-value videos the query pool missed:** Cloud Codes *"DeepSeek Harness Architecture: Insane Software Engineering Behind It"* (49,192 views — the most directly gradeable-against-source video in the pool) and NeuralNine *"The End of Claude Code?"* (196,090 views — the largest-reach video on the subject). Both surfaced in a wider search; neither was in the `DeepSeek Harness` query's 13-result pool. **A deepen pass should anchor these two plus CloudYeti.**
- **The Vietnamese source was read in Vietnamese** (`vi-orig` captions). Its English auto-translation track failed with HTTP 429 and was not retried, which is the better outcome — no translation layer between claim and grade.
- **Nothing was installed.** Standing v242 position (read-and-borrow, install nothing) held throughout. Every operational finding on these pages is another operator's observation, not this ship's.
- **`raw/_inventory.md` and the queue's Completed section** were updated at ship time per routine Phase 7/8.
