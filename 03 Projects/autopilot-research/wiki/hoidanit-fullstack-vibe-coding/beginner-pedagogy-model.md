## The model
- **Two-phase learning loop:** (1) copy foundational knowledge → (2) repeated practice; AI accelerates both but replaces neither.
- **"Ride before disassembling"** [18:58]: for beginners, run the framework and *feel* it before studying internals — the motorcycle is ridden before the engine is opened. Depth is deferred, not skipped.
- **Frontend-first sequencing:** visible results motivate; backend logic comes after the dopamine loop is established; integration last. Explicit anti-pattern: backend-only starts ("boring, no tangible output").
- **Prerequisite ladders:** React before Next.js — *"bicycle → normal motorbike → big bike"* [1:20:49]; library-vs-framework distinction taught at the docs tour (react.dev), with the old-docs trap flagged (legacy content vs react.dev; CRA sunset 2025-02-14 verified).
- **Cadence & scope:** weekly livestream (doc: Monday 19:30), edited upload later that week; series planned at **~20–50 videos** vs a prior ~100-video series (caption-derived at ~3:26 — treat both numbers as approximate); minimum ~1h each; 4 shipped so far, all 76–99 min.
- **Product-first boundary (ep 1):** before any AI usage, the beginner must answer *"bây giờ các bạn muốn xây sản phẩm gì?"* — what product (desktop/web/mobile)? Scope and requirements are never delegated to AI; implementation is. Pragmatic close on AI automation: *"cứ dùng thôi… đáp ứng được nhu cầu thì ok, không thì move on."*
- **Cohort harness:** one evolving Google Doc (links, pins, homework) + Google-Drive starter zips + livestream Q&A ("giao lưu") — zero-LMS, zero-GitHub teaching infrastructure.

## Key Takeaways
- Sequencing (frontend→backend→integration) is a motivation design, not a technical necessity — retention is the constraint being engineered.
- Depth-deferral ("ride first") is explicitly bounded by later fundamentals — vibe coding as entry ramp, not destination.
- 90+ minute weekly episodes + evolving doc + Drive starters = replicable low-ceremony cohort format for any internal team training.
- Prerequisite ladders (React before Next.js) counter the tutorial-default of starting on the highest abstraction.
