## Main-loop digest of the video's claims (English) — for verification

The video shows how to turn an **iPhone / iPad / Mac** into a **local OCR (optical character recognition) server** for free, using Apple's on-device frameworks via a **third-party app**, then calling it over LAN by REST API.

### Framing / setup claims
- **C1** — Apple Intelligence runs a **local on-device model** on iPhone; features named: clean up photo (object removal), Private Cloud Compute, summarize messages, Writing Tools (rewrite/expand/optimize text), Image Playground, summarize audio recordings — and these "work without network" ⇒ there is an on-device model.
- **C2** — Apple **opened the Foundation Models framework** so developer apps on-device can add AI features "with **three lines of code**," using Apple's own model.
- **C12** — On-device speed is credited to "the power of the chip" — **caption garble**: "con chip của Google chip A này rồi của Google" → almost certainly **Apple's A-series / Apple Silicon**, NOT Google. (VERIFY + PIN.)

### The app / architecture claims
- **C3** — A developer (jokingly called "**pháp sư Trung Hoa**" / "anh Trung Quốc" = a Chinese developer) wrote an app named **"iPhone OCR Server"**, on **GitHub + App Store**. It turns the phone into a "powerful local OCR," **exposes port 8000** (configurable) and serves over LAN so any HTTP client (Python or not) can call it by **REST API**.
- **C4** — The OCR is done via the **Apple Vision Framework** (architecture slide says "Apple Vision Framework"). NOTE the presenter's loose framing conflates "Apple Intelligence / Foundation Models" with the Vision framework OCR — the OCR mechanism itself is Vision text recognition. (VERIFY the conflation.)
- **C5** — Settings: **recognition level `accurate` vs `fast`** (accurate = more precise but slower); language correction; auto-detect language; port config (default 8000); a monitoring view (CPU %, per-core, memory, temperature, battery).
- **C6** — The `/upload` endpoint returns **many bounding boxes with coordinates + text values** — fast. Demo draws boxes+labels with **OpenCV Python**.
- **C7** — A second **`doc-ocr` / "paragraph" mode** returns the **full text preserving document structure as Markdown** (incl. reconstructed **tables**) — faster than box mode; keeps layout. Demo writes `ocr.md` and renders a table (a smoothie menu).
- **C9** — Recommendation before starting: enable **Guided Access** on iPhone/iPad to **restrict the device to a single app** (keeps the OCR server stable, no accidental app-switch).

### Results / performance
