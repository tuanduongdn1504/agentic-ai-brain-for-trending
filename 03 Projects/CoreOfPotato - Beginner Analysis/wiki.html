Core of Potato

github.com/hwahao/CoreOfPotato · MIT · v1.0.1 · ~16★ · 7 commits

You log into your own free Grok, Gemini and ChatGPT accounts inside an anti-detect browser. It keeps those tabs alive, drives them by scraping the chat UI's DOM, and re-exposes them to your local tools as an OpenAI-compatible endpoint. A free-tier harvester with an API face.

The request path

01POST /v1/chat/completions   Authorization: Bearer OCtest The shipped caller map registers two clients: OpenClaw and OpenCode. This was built to feed coding agents.
02core/server.py — aiohttp, SSE streaming Source-verified: app.router.add_post("/v1/chat/completions", self.api_chat_completions)
03nav_key = f"{caller}{modu}_{platform}" The 6-character "NaModu" key is auth, session identity and routing key at once — so OCtest always lands in the same conversation.
04worker pool — grok×3, gemini×1, chatgpt×2 URLs recycle on one of three strategies: fixed, time-based (30 min), or usage-based (10 uses, the default).
05CloakBrowser — patched stealth Chromium Corpus subject v69, pinned as cloakbrowser>=0.3.31 and openly credited.
06grok.com · gemini.google.com/app · chatgpt.com Your logged-in consumer sessions. There is no API key to any model anywhere in this system.

How it decides an answer is finished

There is no completion signal, because there is no API contract — so grok.py polls the DOM every 0.25 seconds and calls it done when the text stops changing for about two seconds (stable_count >= 8). Prompts are entered with type_human_like(), followed by asyncio.sleep(random.uniform(0.5, 1.2)) before submitting. Headless is a toggle the docs advise against: it trips bot protection on Grok and ChatGPT.

Worth reading for

This is the cheapest possible argument for paying for a real API. Hold "the answer is done when the text stops changing" next to a streaming API contract, and the value of the contract is immediately legible.

The corpus link

It is built on a previous subject, and says so. The v1.0.0 changelog credits "complete integration with CloakBrowser for advanced stealth browser automation"; requirements.txt pins it; setup_cloak.py pip-installs it and calls ensure_binary() to fetch its Chromium.

Identity was verified independently rather than inferred from the shared name: PyPI cloakbrowser is a drop-in Playwright replacement wrapping a custom Chromium downloaded from CloakHQ — matching corpus subject v69 on author, engine and delivery shape. Because it is credited rather than silently vendored, this is a genuine recursive citation, stronger than the silent bundling seen at v181.

Risk

Verdict

Pilot-avoid. The hardest-fenced subject since CLIProxyAPI v207 — which at least rode official OAuth flows. This drives consumer UIs behind an anti-detect browser specifically to evade the bot protection deployed to stop it.

  1. Terms of service and account bansOpenAI, Google and xAI all prohibit scripted access to the consumer apps. The project's own DISCLAIMER disclaims liability for "damages, consequences, or account bans resulting from the use of this software."
  2. It ships with authentication offVerified in both config and code — and the gateway holds live authenticated sessions to your personal AI accounts. 
    "security": {
  "admin_token": "admin-token-change-me",
  "cors_origins": ["*"],
  "require_auth": false
}

    The require_admin check allows the request when no token is configured. Out of the box, any local process and any web origin reaching 127.0.0.1:2809 can use your accounts. Local-only host binding is the one thing standing in the way.

  3. A black-box binarysetup_cloak.py downloads a pre-compiled Chromium from CloakHQ, an anonymous vendor, which then runs holding your logged-in sessions.
  4. Credentials at rest./data/browser_profiles persists your logged-in browser profiles — session cookies for your Google, OpenAI and xAI accounts — to disk.
  5. AbandonmentNo commits since 2026-06-09, on a project whose entire premise is keeping pace with three vendors' UI changes. UI-scraping rots fast.

Pattern outcome — no mint

Counts unchanged at 46/11. The tempting new standalone — a gateway that browser-automates free consumer web-chat UIs behind an anti-detect browser and re-exposes them as an OpenAI-compatible API — is corpus-first for that surface, and declined anyway:

  • Not world-first, and not close. gpt4free is the canonical flagship of this class, browser automation included, and precedes it by years.
  • The anchor is weak. ~16★, 7 commits, four days of activity, a thin wrapper. The v181 precedent is directly on point: a would-be corpus-first class declined because the anchor was an early, thin orchestration layer.
  • Anti-inflation. Minting a corpus-first row on a 16-star repository for a populated genre is exactly what the discipline exists to prevent.

Recorded as a deferred watch axis instead; if the class earns a mint later it should be minted on a clean exemplar, with this credited as the prior data point.

Two boundaries held

Not a third instance of the v207 gateway standalone — that row is scoped to re-exposing CLI-tool OAuth subscriptions, and this re-exposes free consumer web-UI sessions, a different source mechanism. Its pending promotion trigger is therefore not fired. Not an instance of the stealth-browser standalone either — it is a consumer of that class, not a member.

What to actually take

  • The security anti-pattern, as a live specimen. Auth disabled, wildcard CORS, and "no token configured means allow" on a service holding authenticated sessions — a textbook broken-authentication finding that composes directly with the standing API-security work.
  • The vendor seam. BaseDriver plus a driver registry plus per-platform worker pools is the fourth clean data point on the seam thread, after v196, v210 and v222.
  • The rule it confirms. Official, paid keys per vendor terms — never web-UI scraping, never subscription re-exposure. This is the third catalogued instance of the anti-pattern, and the first that adds evading bot protection to the list.

Never route candidate data through a browser-automated consumer AI account.
