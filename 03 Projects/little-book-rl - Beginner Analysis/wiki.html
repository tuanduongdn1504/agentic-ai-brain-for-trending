What it is

The companion GitHub repo for "The Little Book of Reinforcement Learning" — a short, opinionated, code-anchored primer (157 pages, V1 2026-06-01) that bundles PyTorch reference implementations of every algorithm it covers (algos/, "MC to PPO") plus rigorous dynamic-programming proofs (supplementary/), with a paid print edition on Amazon. It is a learning resource, not a tool: no MCP server, no agent surface, and — verified in the README — zero LLM / RLHF / GRPO content.

The MC → PPO ladder — and why it's on-goal

The canonical classical-RL curriculum a MC→PPO primer covers (standard ladder, not a verbatim TOC — the book.pdf was not read):

  1. MDPs & the RL problemagent↔environment loop, return, discount γ, the Markov property
  2. Value functions & Bellman equationsV(s), Q(s,a), the fixed-point structure the supplementary/ proofs formalize
  3. Dynamic programmingpolicy iteration, value iteration — the algorithms with rigorous convergence proofs
  4. Monte Carlo methodslearning from complete sampled episodes, no model needed (the "MC")
  5. Temporal-difference learningbootstrapping — SARSA, Q-learning, TD(λ)
  6. Function approximationtables → neural nets → deep RL (DQN-style value approximation)
  7. Policy gradientsREINFORCE — optimize a parameterized policy directly
  8. Actor-criticlearned critic + policy actor; advantage estimation (A2C, GAE)
  9. PPO — the endpointclipped-surrogate policy optimization, the modern applied workhorse
⭐ Why a classical-RL book is on-goal (Goal #1)

The ladder ends exactly where the modern-agent training stack begins. PPO is literally the algorithm inside RLHF. Actor-critic + advantage estimation (GAE) is the machinery behind GRPO / RLVR / agentic-RL — the paradigms that now train reasoning models and coding agents. This book is the "what agents are trained with" foundation layer — one step up from LLMs-from-scratch v74's "what an LLM is." That's why it's (b) MODERATE / GOAL-ALIGNED, not FAIL — and why it's one layer removed from the direct Claude/agent core, so not STRONG.
