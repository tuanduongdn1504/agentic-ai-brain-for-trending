What it is

Hallmark is a markdown design skill — a SKILL.md plus a folder of reference rule-files — that a coding agent installs so the pages it produces, audits, redesigns, or reverse-engineers avoid the generic "AI slop" aesthetic. Install with npx skills add nutlope/hallmark (the agentskills.io verb) or copy it into a Claude Code / Cursor / Codex skill directory. Built by Together AI; author Hassan El Mghari (@nutlope), a DevRel lead there and a prolific indie AI-app builder (RoomGPT, LlamaCoder, BlinkShot). It is a design-taste layer, not a framework or an MCP server — the repo is CSS/HTML/markdown assets plus a static demo at usehallmark.com.

Four verbs
default

Generate

Pick one of 21 macrostructures, apply the rule-sets, self-critique, then a 57-gate sweep. Catalog theme unless the brief signals custom. Each build must differ from the last.

audit ‹target›

Score

Grade existing code against the anti-patterns and return a ranked punch-list. Read-only — no edits.

redesign ‹target›

Rebuild

Replace the visual and interaction layer; preserve routes, information architecture, brand, and copy. --mood picks a direction.

study ‹url|shot›

Extract DNA

Read macrostructure, archetypes, type-pairing, and colour from a reference; diagnose; optionally export a portable design.md.

The machinery

The enforcement is a 57-gate slop-test (#1–#57) across six axes, preceded by a pre-emit self-critique: the skill scores its own planned output 1–5 on six named axes and anything under 3 triggers a revision pass before the gate sweep. Sampled verbatim from references/slop-test.md:

slop-test.md57 enumerated gates · 6 axes
#2Is there a purple-to-blue (or cyan-to-magenta) gradient anywhere — including a background-clip:text gradient headline?
#6Is the hero min-height:100vh with the eyebrow, title, lede, and CTA all stacked on one centred vertical axis?
#22Does any neutral / surface colour use oklch(… 0 …) — zero chroma?
#34Does the page scroll horizontally on any viewport between 320px and 1920px?
#42Is the nav the AI default — wordmark-left, 4–5 inline links centred, button-right?
#46Does the page state any quantitative claim the user didn't supply and the model fabricated?

/* pre-emit: score 1–5 on Philosophy · Hierarchy · Execution · Specificity · Restraint · Variety — anything <3 triggers a revision pass */

Six universal disciplines

  • Pre-emit self-critique (P/H/E/S/R/V, stamped in the artifact)
  • Honest copy — no fabricated metrics, testimonials, or logos
  • Locked tokens — named CSS variables only; no inline OKLCH/hex
  • No re-drawn chrome — no fake browser / phone / IDE frames
  • Mobile at 320 / 375 / 414 / 768px — a non-negotiable floor
  • Typography purity — italic headers banned; emphasis via weight / colour / underline

Also: 20 named themes (Specimen, Terminal, Midnight, Riso, Cobalt, Aurora, Editorial…), 21 macrostructures, 46 component archetypes, 10 rule-files (typography, OKLCH colour, 4pt layout, motion, copy, anti-patterns, responsive…), and a token-efficiency rule: "never load the whole index plus more than one per-macro file in a single build."
