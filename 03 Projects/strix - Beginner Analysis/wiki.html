The pitch

Point it at a URL, a domain, a repo, or a local codebase. It spins up a graph of specialized AI agents that run inside an isolated Kali Docker sandbox stocked with ~60 real pentest tools — and each agent thinks, calls a tool, reads the output, and iterates like a human attacker.

The discipline that makes it worth trusting: a finding is only reported once a separate validation agent proves it with a working proof-of-concept. No exploit, no report — so it claims zero false positives by construction ("if the PoC works, the vulnerability is real"). In white-box mode it also writes the fix as a code diff.

Graph of Agents · the crown jewel

The root agent is an orchestrator, not a tester — it delegates, tracks todos, monitors results, and spawns specialist children reactively as attack surface is discovered. Nested trees, one job per agent, mandatory independent validation.

black-box   Discovery→Validation · PoC→Reporting
white-box   Discovery→Validation · PoC→Reporting→Fixing · diff
◈ spawn→ message◆ finish○ wait◼ stop (cascade)

Built on the OpenAI Agents SDK + LiteLLM (not the Claude Agent SDK). Async parent/child coordinator · inbox messaging · graceful cascade-cancel · max_turns=500 · optional --max-budget-usd dollar cap. The "validation is mandatory — never trust scanner output" rule is a maker/checker pattern, mirroring the vault's own loop-verifier (v189).

Dual-use · read before piloting

⚠ This is an offensive tool with no built-in authorization guard

  • Only test what you own / are authorized to test. The OSS CLI has zero enforcement — a README warning is the only guard. Running exploits elsewhere risks CFAA / cybercrime / GDPR exposure.
  • Telemetry is opt-out, default-ON → export STRIX_TELEMETRY=0. (README says it never collects vuln details; the code does send severity counts + token spend.)
  • Set --max-budget-usd — it's off by default. ~$3.37/challenge on the benchmark; a deep scan runs into real money.
  • Never against production — aggressive scans can DoS the target (independently observed: DB pool exhaustion).
  • Prefer pip install strix-agent over curl|bash (no digest pin / no signature); run install-snapshot first.
