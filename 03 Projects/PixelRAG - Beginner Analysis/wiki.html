PixelRAG

Web screenshots beat text for retrieval-augmented generation.

Search any document by how it looks, not just the text it contains. A Berkeley SkyLab / Databricks research system that renders documents to screenshots, retrieves over the images, and reads pixels straight into a vision-language model — no text conversion. The corpus's first visual/screenshot-based RAG.

01The thesis

Parsing to text throws away everything the eye uses.

Traditional RAG parses a document into text chunks, embeds the text, and feeds text to the reader. Tables, charts, columns, diagrams, spatial layout — the structure a person reads at a glance — is destroyed at parse time. PixelRAG's bet, stated in the title: text RAG "loses the table"; PixelRAG "retrieves the right tile, and the reader reads the number straight off the image."

The surprising claim from the paper (arXiv 2606.28344): rendered screenshots beat text baselines not only on visual questions but on text-centric benchmarks too — NQ, SimpleQA — because a rendered page is a richer, layout-preserving representation than lossy parsed text. Reported gains up to +18.1% over text-based RAG, including agentic benchmarks. (Authors' own paper-stated results — not reproduced here.)

02How it works

Two stages, entirely in pixel space.

Render — pixelshot turns web pages / PDFs / images into screenshot tiles via headless Chromium (Playwright / CDP). Retrieve — a VLM embedding model (Qwen3-VL-Embedding-2B, LoRA-fine-tuned on screenshot data) embeds the tiles; search happens over the images themselves. Retrieved screenshots are fed directly as pixels to a reader VLM — no intermediate text.

04Pattern outcome — NO MINT

Corpus-first, but not world-first — and a research system, not a capability class.

PixelRAG is corpus-first (collision-clean, sanity-anchored hand-grep) for visual/screenshot-based general-document RAG. That earns no §C mint: (1) corpus-first-for-a-technique ≠ a mintable capability class — a research retrieval system + a fine-tuned model enters as a corpus-knowledge data-point (the TimesFM v193 / meetily v196 / AIRI v210 discipline, §28); (2) it is NOT world-first — ColPali (2024) and DSE / Document Screenshot Embedding (arXiv 2406.11251, 2024) precede; visual-document retrieval is an active area.

Reviewable alternative (recorded)

A §C-standalone MINT — "Visual / Screenshot-Based Multimodal Document RAG" N=1 — is defensible on the fff v194 / serve-sim v183 / page-agent v199 corpus-first-for-surface precedent (a genuinely distinct retrieval modality). It loses to NO-MINT on research-system-not-tool + §28 + not-world-first. Promotion-eligible at a 2nd visual-RAG subject (~v212 audit). Either way — counts UNCHANGED 46/11.

07What to distrust

  • The hard AI is upstream — Qwen3-VL-Embedding-2B + a LoRA + a reader VLM. PixelRAG orchestrates + fine-tunes; it doesn't invent the vision model.
  • Benchmarks are the authors' own — "+18.1%" / "beats text on NQ/SimpleQA" are paper-stated, not independently reproduced.
  • NOT world-first (ColPali / DSE precede) · NOT source-cloned (WebFetch + arXiv + README) · young (v0.4.0, 4 releases).
  • Pixels cost tokens — feeding a screenshot to a VLM is heavier than parsed text; the accuracy gain has an efficiency price the README doesn't quantify.
