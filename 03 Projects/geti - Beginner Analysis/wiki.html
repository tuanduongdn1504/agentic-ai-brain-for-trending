What it is

Geti is an interactive application that takes you from raw images to a deployed vision model in one place — annotate → train → optimize → run inference → improve, in a rapid train–predict–annotate loop, from as few as 10–20 labelled images. It runs locally (single container or native Windows app, no cloud) and auto-exports every model with OpenVINO™ for the Intel XPU portfolio (Arc GPUs, Core Ultra) — NVIDIA CUDA and CPU also supported. SOTA catalog (RF-DETR, DINOv3 DETR, YOLO26, Mask R-CNN), smart annotation via Segment Anything / SAM3, and COCO/VOC/YOLO dataset I/O.

The training engine is getitune (PyPI getitune) — the successor to Intel's OpenVINO Training Extensions (otx), which this repo previously hosted. Geti v3.0.0 is the Apache-2.0 open-source release of what was a licensed Intel product (part of the Tiber Edge Platform; docs at docs.geti.intel.com).

The load-bearing finding — a first-party agent-skill suite

A plain CV platform would be off both goals. Geti is not plain: the repo ships AGENTS.md, CLAUDE.md, and a canonical skills/ directory in the open agentskills.io format, mirrored cross-harness by committed symlinks into .claude/skills/ + .agents/skills/ (“so a fresh clone works for agents, no setup step”), kept honest by a sync then validate pre-commit/CI gate. A coding agent (Claude Code, etc.) can drive the whole vision-ML loop through these skills.
